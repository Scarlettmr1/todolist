# taskapp — React Native Todo List

A React Native task manager built with Expo and React Native Elements.

## Features
- View default tasks on load
- Check/uncheck tasks (completed tasks show strikethrough)
- Add new tasks via input + "Add" button or the Enter key

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Install web packages
npx expo install react-dom react-native-web @expo/metro-runtime

# 3. Start the dev server
npx expo start

# Press W to open in the browser
```

## Deploy to GitHub Pages

```bash
# Build and deploy
npm run deploy
```

Then go to your repo → **Settings → Pages** → set source to the `gh-pages` branch.

Your app will be live at: `https://<your-username>.github.io/taskapp/`

## Project Structure

```
taskapp/
├── App.js          ← main component (all logic + UI)
├── app.json        ← Expo configuration
├── babel.config.js ← Babel preset for Expo
├── package.json    ← dependencies and scripts
└── assets/         ← icons/splash (auto-generated by Expo)
```
